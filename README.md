# 🌱 Agrinho - Agro Forte, Futuro Sustentável

## 📖 Sobre o Projeto

Este site foi desenvolvido para o **Programa Agrinho**, uma iniciativa que promove a educação no campo e na cidade, abordando temas essenciais como saúde, segurança, meio ambiente e sustentabilidade.

O tema central **"Agro Forte, Futuro Sustentável"** explora como a agricultura moderna pode ser produtiva e, ao mesmo tempo, responsável com o meio ambiente, garantindo um futuro melhor para as próximas gerações.

## 🎯 Objetivos

- Conscientizar sobre práticas agrícolas sustentáveis
- Mostrar a importância da preservação ambiental no campo
- Apresentar soluções inovadoras para um agro mais verde
- Estimular o pensamento crítico sobre alimentação e consumo

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Design responsivo com animações
- **JavaScript** - Interatividade (quiz, calculadora de pegada, animações)
