# 🌱 Agrinho - Agro Forte, Futuro Sustentável

## 📖 Sobre o Projeto
Site educativo desenvolvido para o concurso **Agrinho**, com o tema **"Agro forte, futuro sustentável"**. O objetivo é conscientizar sobre a importância da agricultura sustentável, suas práticas inovadoras e seu papel na construção de um futuro mais equilibrado entre produção e preservação ambiental.

## 🎯 Objetivos
- Promover a conscientização sobre agricultura sustentável
- Apresentar práticas inovadoras do agro brasileiro
- Relacionar o agro com os Objetivos de Desenvolvimento Sustentável (ODS)
- Oferecer ferramentas interativas de aprendizado (quiz e calculadora)
